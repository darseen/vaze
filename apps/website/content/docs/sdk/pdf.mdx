`vaze.pdf` works on PDFs on the server, which needs Vaze 4.8.0 or later. It
needs `files:read`, and every method returns the [response
envelope](/docs/sdk#response-shape), with the result as a `Blob`. On a server
that [turned the PDF tools off](/docs/getting-started/configuration#tools),
every method sets `error` with status `404`. [`tools()`](/docs/sdk#tools) tells
you beforehand whether a server has them.

## Sources

Each method takes stored files by `id`, files from your device as `file`, or
both, in any order. A device file is a web
[`File`](https://developer.mozilla.org/en-US/docs/Web/API/File), or in React
Native a `{ uri, name, type }` reference, and the server keeps it only until
the result is sent.

```ts
const { data, error } = await vaze.pdf.merge([
  { id: "cover-id" },
  { file },
  { id: "appendix-id" },
]);

if (data) {
  const { blob, filename } = data; // e.g. "cover (merged).pdf"
  await fs.writeFile(filename ?? "merged.pdf", Buffer.from(await blob.arrayBuffer()));
}
```

A password-protected PDF, or a file that can't be read, sets `error` with
status `422`. A server busy with other PDFs answers `503`; try again shortly.

## Merge

`merge(sources)` joins 2 to 100 PDFs into one, in the order given.

## Split

`split(source, options?)` cuts a PDF into parts and returns them as PDFs in a
ZIP, such as `report (pages 1-3).pdf`.

```ts
const { data } = await vaze.pdf.split({ id: "file-id" }, { ranges: "1-3, 7, 10-" });
```

| Option   | Description                                                                         |
| -------- | ----------------------------------------------------------------------------------- |
| `ranges` | Pages and ranges, each of which becomes one PDF. `10-` runs to the last page        |
| `every`  | A part every so many pages                                                          |

Pass one of the two, or neither for a PDF of each page.

## Edit pages

`edit(source, options)` rearranges a PDF's pages, numbers them, and retitles
the document.

```ts
// page 3 first, then page 1 turned a quarter clockwise; page 2 is left out
const { data } = await vaze.pdf.edit(
  { id: "file-id" },
  { pages: [3, { page: 1, rotate: 90 }], pageNumbers: true, title: "Signed contract" },
);
```

| Option        | Description                                                                                                                      |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `pages`       | The pages to keep, in their new order: a page number from 1, or `{ page, rotate }` with `rotate` 90, 180 or 270. Pages may repeat |
| `pageNumbers` | Number the pages at the foot of each                                                                                             |
| `title`       | The new title. Without it, the original's is kept                                                                                |

Removed pages are gone from the file, not only hidden.

## Images to PDF

`fromImages(sources, options?)` makes a PDF with one image on each page, from
JPEG, PNG, WebP, AVIF, GIF, TIFF, SVG and HEIC images.

```ts
const { data } = await vaze.pdf.fromImages(
  [{ id: "scan-1" }, { id: "scan-2" }],
  { pageSize: "a4", margin: 18 },
);
```

| Option     | Description                                                                                   |
| ---------- | --------------------------------------------------------------------------------------------- |
| `pageSize` | `"fit"` (the default) gives each image a page of its own size; `"a4"` and `"letter"` fit it in |
| `margin`   | Space around each image in points, from 0 to 144                                              |

## Document to PDF

`fromDocument(source)` turns a Word, Excel, PowerPoint or OpenDocument file,
RTF, CSV or plain text into a PDF.

```ts
const { data } = await vaze.pdf.fromDocument({ id: "report-docx-id" });
```

## Sending the request yourself

Each method has a URL to post to, such as `mergeUrl()` or `editUrl()`, for
streaming the result to disk or showing progress with
[`authHeaders()`](/docs/sdk#fetching-urls-yourself). The page count is in the
`X-Pdf-Pages` header, and a split's number of parts in `X-Pdf-Parts`. See [the
endpoints](/docs/api-reference/pdf) for everything they accept.
